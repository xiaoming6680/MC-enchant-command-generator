# Minecraft Java 附魔指令生成器

不用手写复杂的 NBT 或物品组件格式，也能快速生成带附魔物品的 `/give` 指令。

**在线使用：[打开附魔指令生成器](https://enchant.xiaoming6680.link/)**

> 本工具适用于 **Minecraft Java Edition**，不支持基岩版（Bedrock Edition）。

![界面演示](演示图库/image.png)

## 怎么使用？

只需四步：

1. **选择游戏版本和目标玩家**
   - 先选择你正在游玩的 Java 版本。
   - 目标可以选择所有玩家、最近玩家、自己，也可以输入具体玩家名称。
2. **选择物品**
   - 搜索并选择武器或工具，也可以直接输入自定义物品 ID。
   - 数量必须是大于或等于 `1` 的整数。
3. **添加附魔**
   - 点击“新增附魔”，选择附魔并填写等级。
   - 可以添加多条附魔；如果不需要附魔，也可以直接生成普通物品指令。
4. **复制指令**
   - 确认右侧预览无误后，点击“复制指令”。
   - 回到游戏，将指令粘贴到聊天框或命令方块中执行。

目标玩家和物品为必填项。填写不正确时，网页会在对应位置给出提示。

## 支持哪些版本？

| 游戏版本 | 使用的指令格式 |
| --- | --- |
| Java 1.21.5+ | 新版物品组件简化格式 |
| Java 1.20.5–1.21.4 | 物品组件 `levels` 格式 |
| Java 1.13–1.20.4 | 字符串 ID 的 NBT 格式 |
| Java 1.8–1.12.2 | 数字附魔 ID 的旧版 NBT 格式 |

选择版本后，物品和附魔列表会自动隐藏该版本中不存在的内容。

## 目标玩家怎么选？

- `@s`：执行指令的自己
- `@p`：距离最近的玩家
- `@a`：所有玩家
- `@r`：随机玩家
- 玩家名称：只把物品给予指定玩家

如果只是想给自己物品，通常选择 `@s` 最方便。

## 指令示例

例如：给所有玩家一把带有锋利 V 的钻石剑。

Java 1.21.5+：

```mcfunction
/give @a diamond_sword[enchantments={sharpness:5}]
```

Java 1.20.5–1.21.4：

```mcfunction
/give @a diamond_sword[enchantments={levels:{sharpness:5}}]
```

Java 1.13–1.20.4：

```mcfunction
/give @a diamond_sword{Enchantments:[{id:"minecraft:sharpness",lvl:5s}]}
```

Java 1.8–1.12.2：

```mcfunction
/give @a minecraft:diamond_sword {ench:[{id:16,lvl:5s}]}
```

当物品数量为 `1` 时，生成器会省略命令末尾的数量；数量大于 `1` 时会自动补充。

## 自定义物品和附魔

下拉列表中没有需要的内容时，可以直接输入 ID：

- 原版 ID：`diamond_sword`、`sharpness`
- 带命名空间的 ID：`minecraft:diamond_sword`、`minecraft:sharpness`
- 模组或数据包 ID：按照对应模组或数据包提供的命名空间填写

不知道物品 ID？可以使用网页中的“查询物品 ID”入口。

> Java 1.8–1.12.2 使用数字附魔 ID。这个模式只能转换生成器内置且具有旧版数字 ID 的附魔，自定义附魔通常无法使用。

## 指令无法执行怎么办？

可以依次检查：

- 游戏是否为 Java 版，并且网页中选择的版本是否正确。
- 单人世界是否已开启作弊，或你在服务器中是否拥有执行命令的权限。
- 指令是否从开头的 `/give` 完整复制。
- 自定义物品 ID、附魔 ID 中是否包含空格或拼写错误。
- 使用命令方块时，是否需要移除指令开头的 `/`。
- 模组或数据包提供的物品、附魔是否已在当前存档或服务器中加载。

## 小提示

- 附魔等级可以超过生存模式的通常上限，前提是对应版本允许该指令格式。
- “清空附魔”只会删除附魔槽位；“重置全部”会恢复整个生成器的初始状态。
- 页面会实时检查输入，但不会判断所有附魔之间是否互斥，也不会限制附魔适用的物品。
- 在服务器使用前，建议先确认服务器规则允许使用相关指令和超常附魔。
